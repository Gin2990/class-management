# Ứng Dụng Quản Lý Lớp Học & Gia Sư (Next.js + Prisma + SQLite)

Hệ thống quản lý lớp học, học viên, lịch học theo giờ, điểm danh và học phí chuyên nghiệp dành cho giáo viên và trung tâm.

## 🚀 Bắt đầu nhanh
- **Cài đặt lần đầu trên máy mới:** Nhấp đúp vào `cai_dat_thu_vien.bat`
- **Khởi động ứng dụng:** Nhấp đúp vào `khoi_dong_app.bat` hoặc gõ `npm run dev`
- **Địa chỉ truy cập:** [http://localhost:3000](http://localhost:3000)
